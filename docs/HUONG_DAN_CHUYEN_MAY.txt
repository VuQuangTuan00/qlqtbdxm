HƯỚNG DẪN XUẤT VÀ CHUYỂN MÁY - QLQT BẢO DƯỠNG XE MÁY
=====================================================

XUẤT GÓI CHUYỂN MÁY
--------------------
Trong ứng dụng, vào Cài đặt hệ thống > File backup > Sao lưu toàn bộ.
Chọn nơi lưu một file .zip. Gói backup version 3 gồm:
- database/app.sqlite: bản chụp cơ sở dữ liệu SQLite.
- files/vehicle-images: chỉ chứa ảnh JPG, PNG, GIF hoặc WEBP.
- files/maintenance-files: chỉ chứa tài liệu PDF.
- manifest.json: phiên bản gói, danh sách file, kích thước và SHA-256.

Thư mục uploads cũ không được đưa vào backup version 3. Ứng dụng vẫn hỗ trợ
khôi phục các gói version 2 đã tạo trước đây.

KHÔI PHỤC TRÊN MÁY ĐÍCH
-----------------------
1. Cài đặt ứng dụng và mở ứng dụng một lần.
2. Đăng nhập bằng tài khoản quản trị.
3. Vào Cài đặt hệ thống > File backup > Khôi phục từ backup.
4. Chọn file ZIP. Ứng dụng sẽ kiểm tra manifest, checksum, database và loại file.
5. Xác nhận khôi phục. Ứng dụng tự tạo một safety backup trước khi thay dữ liệu.
6. Sau khi ứng dụng khởi động lại, kiểm tra danh sách xe, ảnh và tài liệu PDF.

LƯU Ý
-----
- Không cần cài SQL Server hoặc dùng SSMS.
- Không sửa tay manifest hoặc ghép file từ hai gói backup khác nhau.
- Không đổi đuôi file để đưa loại file khác vào thư mục ảnh hoặc PDF.
- Giữ file ZIP ở nơi an toàn và chuyển bằng USB hoặc phương tiện lưu trữ
  được phê duyệt.
- Nếu khôi phục thất bại, ứng dụng sẽ hoàn tác dữ liệu trước đó.
