HƯỚNG DẪN CÀI NHANH

1. Cài và cấu hình Microsoft SQL Server trên máy chủ.
2. Tạo database và tài khoản SQL Server riêng cho ứng dụng; cấp quyền migration, đọc/ghi và backup/restore cần thiết.
3. Cài ứng dụng từ file Setup.exe hoặc chạy `npm start` khi phát triển.
4. Ở lần mở đầu tiên, nhập Server, Port (nếu có), Database, User và Password trên màn hình thiết lập SQL Server.
5. Nhấn "Kiểm tra kết nối", sau đó nhấn "Kết nối & Khởi động".

Ứng dụng lưu cấu hình trong db-config.json thuộc Electron userData. Không tạo hoặc sử dụng file .env.

Nếu SQL Server nằm trên máy khác, cấu hình TCP/IP và firewall trong phạm vi mạng nội bộ được phép. Khi backup qua mạng, dùng đường dẫn UNC và cấp quyền cho cả dịch vụ SQL Server lẫn tài khoản Windows chạy ứng dụng.
